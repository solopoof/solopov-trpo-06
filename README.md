## Результат
Приложение читает и изменяет dataset/notes.json, добавляет заметки с уникальными ID и переключает их статус. Запись выполняется через временный файл и атомарное переименование; операции защищены lock-файлом. dataset/users.json используется для выбора пользователя, имя хранится в PHP-сессии. dataset/session_scenarios.json загружается и отображается в интерфейсе.

Обработчик находится в public/index.php и src/NotesController.php, хранилище — в src/NoteRepository.php, HTML — в templates/. Функция render() передаёт массив данных шаблону. POST завершается redirect HTTP 303. Неизвестный параметр page возвращает HTTP 404. Отсутствующий и повреждённый JSON обрабатывается понятным сообщением.

## Запуск
PHP 8.1+. Папка dataset должна быть доступна PHP для записи в notes.json.
php -S localhost:8000 -t public
Откройте http://localhost:8000/?page=notes.

## Проверка сессии в браузере
1. Откройте приложение в обычном окне: отображается Гость.
2. Выберите Student A и сохраните: после redirect имя остаётся в шапке.
3. Откройте приложение в приватном окне: создаётся отдельная сессия, отображается Гость.
4. Сбросьте сессию в обычном окне: имя снова становится Гость.
5. Добавьте заметку и переключите статус.
6. Откройте /?page=unknown: сервер возвращает HTTP 404.

Приватный режим использует отдельное хранилище cookies, поэтому PHP session ID не совпадает с обычным окном. Поведение закрытия приватного окна зависит от браузера; обычно его временные данные удаляются после закрытия последнего приватного окна.

## Ограничения
JSON удобен для небольшой учебной нагрузки, но не заменяет транзакционную БД. Блокировка защищает операции записи приложения, однако сложные конкурентные сценарии, резервное копирование и разграничение доступа требуют отдельного решения. PHP-сессия хранит состояние браузера и не является системой аутентификации.

# Практическая работа №06 — JSON, сессии и MVC-разделение

**Студент:** Солопов Антон  
**Группа:** ЭПБО-01-25

## Реализовано
Чтение и запись заметок в JSON; добавление заметки и переключение статуса; блокировка файла на время записи через flock; имя пользователя хранится в PHP-сессии; сброс сессии; разделение контроллера и шаблона; безопасный вывод.

## Запуск
PHP 8.1+ с mbstring:
```bash
php -S localhost:8000 -t public
```
Откройте http://localhost:8000. PHP должен иметь право записи в `dataset/notes.json`.

## Проверка
`php -d zend.assertions=1 -d assert.exception=1 tests/repository_test.php`
Проверьте сценарии из `dataset/session_scenarios.json`: новая сессия, установка имени, сброс. Добавьте заметку и измените её статус.

## Структура
`public/index.php` — точка входа; `src/NotesController.php` — запросы и сессия; `src/NoteRepository.php` — JSON; `templates/notes.php` — отображение; `dataset/` — исходные данные; `tests/` — тест репозитория.

## Поток данных
Контроллер выполняет действие POST, затем шаблон получает подготовленный массив. В шаблоне нет операций чтения/записи файла и управления сессией.

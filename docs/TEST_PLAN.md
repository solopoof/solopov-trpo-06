# План проверки

1. Открыть приложение в новой сессии и убедиться, что имя по умолчанию — «Гость».
2. Установить имя и обновить страницу: имя должно сохраниться.
3. Сбросить сессию: снова отображается «Гость».
4. Добавить заметку: она появляется в JSON и списке.
5. Переключить состояние заметки и обновить страницу.
6. Проверить пустое название и неизвестный ID.
7. Проверить тест репозитория через PHP assertions.
